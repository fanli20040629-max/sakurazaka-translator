## 已确认设计

在现有候选卡片中提供保守节点分组建议、原文确认和 DeepSeek 文本翻译。所有候选仍由用户选择；同一列表项内有结构和不重叠位置依据才建议合并，不对 OCR 行按距离猜聊天边界。可关闭分组并逐片段发送。翻译在结果卡片显示，暂不实现跟随原消息的气泡。

表情保护只保护输入中已经存在的符号/组合 Emoji/换行，采用可校验占位符往返。OCR 已漏掉或误认的符号保留待核对，不把数字/汉字替换成猜测的表情。不上传图片；云端视觉识别另行实现。

翻译前展示实际发送的原文、服务商和风格。仅在再次点击发送时联网；API Key 在手机设置中输入并用 Keystore 加密保存，不预填、不记录。使用固定 DeepSeek HTTPS 地址，可配置模型和两个风格档案。无 Key 也可运行取字和全部离线测试。禁止自动重试收费请求。

## 验收案例

1. 同列表项的两行正确建议合并；不同列表项即使同文也分开；OCR 不自动与节点合并。
2. `ありがとう～💗\n👩🏽‍💻 ❤️ 🇯🇵 1️⃣ 米9` 的符号和换行往返一致；缺占位符、重复、调换或新增 Emoji 均拒绝展示为合格译文。
3. 返回 ID 顺序变化可重排；数量、ID 或文本错误拒绝；不会将第二条译文显示到第一条。
4. 关闭、换页、变更选择或风格后迟到结果不上屏；取消不启动隐式重试，不保存聊天正文。
5. 未确认发送时无请求；确认区准确展示待发送条目与风格；错误仅显示可读分类和操作建议。
6. 真机验证 Key 保存/删除/重启、设置页不被取字、网络错误、实际 DeepSeek 模型支持、符号质量、卡片交互和长时间使用。
