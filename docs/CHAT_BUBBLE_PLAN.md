# 自动分组与原文附近显示（2026-09-21）

基线：92fc7cc（生产代码仍为 dfbcded）。用户要求优先推进这两项，真机验证在 Windows 继续。本轮分支：codex/chat-bubble-layout。

## 设计与边界

- 复用 MessageGrouper、候选选择和确认发送链路。自动分组仅使用最近的 collectionItem，或已识别列表容器中重复且不相交的直接子项；不凭行距、文本相同或作者名字猜消息。辅助信息夹在正文之间时不跨越合并。无证据、循环结构、来源冲突、截断都保留片段。
- 在候选区提供“整组选择”，仍可展开逐片段调整；所有候选默认不选，修改选择使旧确认失效。关闭分组后请求恢复为原片段。OCR 保留原有独立候选，不自动融合或映射截图坐标。
- 真实翻译成功后增加“贴近原文显示”。全屏透明、不可触摸的译文层展示最多四条完整中文；保留编号，用淡色圆角与边框，避开可见节点正文、媒体、控件、系统区域和入口按钮。用实际测量的文字尺寸布局，不截断长译文、不缩小到难读。
- 仅屏幕坐标有效且没有风险警告的节点项可定位。只在原文上下或左右紧邻处放置，不能把译文挤到另一条消息旁。无法放置的项留在完整结果卡片，并提示数量。
- 显示译文层时隐藏原文整理大卡片；入口变为“返回译文”，切回可查看全部结果。页面滚动、内容变化、锁屏、旋转、关闭或重新选择时清理译文层；首版不跨滚动追踪、不重新联网。
- 继续使用 PageToken 和单请求取消机制，显式发送是唯一联网入口。新窗口单独登记所有权，不能忽略所有本应用事件。

## Windows 必测（不能用桌面测试替代）

G01：两位偶像页逐条比对组内原文；重复短句不合并，不跨作者/时间/列表项，未知结构退回片段。

G02：整组选择后取消一行，追加 OCR 后选择不丢；关闭合并开关后确认区按片段展示；任何更改使旧确认失效。

B01：确认中文返回后切换附近显示与完整卡片，不增加请求；编号、正文和译文对应一致。

B02：长文、密集气泡、屏幕边缘、状态栏、导航栏、分屏和字体放大：不覆盖已知原文区域、不出屏；放不下的完整译文在卡片可读。

B03：译文层不阻断原 App 滑动；滑动、切页、锁屏、旋转立即清理；键盘弹出/收起及窗口尺寸改变清理，不依赖输入文字触发；迟到回调不能恢复旧位置。

B04：自身窗口创建/返回不误清理结果；目标页事件仍能失效，设置页无译文层；重复切换/关闭至少 20 次无多余窗口或崩溃。

实机看到无障碍节点未覆盖的内容仍可能被遮挡，需记录节点覆盖率与样本，不宣称视觉零遮挡。本轮不处理图片识别和自动风格学习。

## 代码定位与审查补充

- MessageGrouper：分组及整组选框成员；NodeTreeReader/ProbeModels：collection 信息；CandidatePanel：整组选框和原片段同步。
- BubbleLayout：屏幕矩形、候选宽度、边界/碰撞及回退；BubbleTranslationOverlay：实际 TextView 测量、系统/键盘区域、不可触摸窗口与释放。
- TranslationPanel：翻译成功后显示按钮；TranslatorAccessibilityService：页面身份、显示切换与取消/清理。没有第二套网络实现。
- 独立审查发现固定 260dp 宽度不适合侧边空隙，已增加实际测量的侧边宽度（至少 140dp），完整长文仍回退。另补齐键盘 Insets/窗口尺寸变化监听，防止旧译文覆盖变化后的可用区域。整组与独立候选保持阅读顺序。
