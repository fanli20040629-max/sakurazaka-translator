## 查验中发现的说明偏差

1. 节点 ID 是 n2:text / n10:text，原来的尾部数字解析没有覆盖这个格式。
2. ML Kit 返回顺序不等于屏幕坐标顺序；现有 OCR 汇总只保持了返回顺序。
3. OCR 全部标为 MEDIA_CANDIDATE，工厂排除 METADATA 不代表 OCR 的作者/时间已自动过滤。
4. 一行 OCR 是一个片段，不一定是一条聊天消息；确认数量应显示为片段数。
5. Java 自测不编译 Android Service，也不等价于 APK 构建或真机通过。
