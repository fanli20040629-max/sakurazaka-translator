## 1. 版本 6 的实现基础（历史）

1. **节点/OCR 统一候选**：先出现节点，后续追加 OCR 不重置勾选；截图失败仍保留节点。原文中的表情、空格和换行不被 OCR 覆盖。
2. **保守分组建议**：只对同一列表项祖先中的选中节点提出合并；位置缺失、重叠、辅助控件、字段冲突或读取截断时不合并。不同列表项和 OCR 不强行拼接。可以关闭建议分组，逐片段翻译。
3. **符号往返保护**：对输入中已有的 Emoji、组合序列、波浪号、部分其他符号和换行建立占位符；模型漏写、重复、错序或新增受保护符号时拒绝结果。没有把“9/米”猜改成 Emoji，也没有恢复 OCR 已丢失的内容；复杂颜文字仍需样本验证。
4. **DeepSeek 文本接口**：固定 HTTPS 地址；模型名可编辑；每次先确认实际发送的原文与风格，再发一次请求。返回项按消息 ID 校验和重排，不按模型返回顺序盲目贴回。
5. **设置**：首页入口可输入 API Key、模型，以及两个可编辑的偶像名称/中文风格摘要；手动选择当前档案。Key 用 Android Keystore 加密后存储，不回显、不进日志、不进仓库；空 Key 输入保留原值，删除有独立按钮。
6. **中文卡片**：在当前结果卡片中按编号显示原文和中文。不是自动定位到目标 App 原气泡旁边的显示层。
7. **取消与隔离**：改选择、改分组、关卡片、切页或锁屏后取消旧翻译显示。仍在结束的物理请求占用不被伪装清空，不启动第二个并行翻译。45 秒总截止、10 秒连接和 25 秒读取超时；不自动重试收费请求。
8. **设置页隔离**：密钥设置页禁截图，并从助手取字范围排除；这必须在手机验证。备份/设备迁移规则显式排除共享偏好，避免迁移无法解密的凭据。

当前不会自动辨认所有作者/时间，也不会自动知道哪位偶像正在聊天；所有候选默认不选。Blog 的自动导入/分析、云端图片识别和跟随消息的中文气泡尚未实现。

## 9. 故障处理与矛盾核实顺序

### 9.1 统一处理步骤

1. 记录最先失败的阶段、精确命令/操作、源码和版本、关键错误类别。后续连带错误不要误当多个独立根因。
2. 用最小合成输入复现，按下面分流判断是环境、配置、代码还是目标页面适配问题。
3. 修改前记录预期与实际差异；纯逻辑/协议问题添加能复现失败的测试。Android 生命周期问题保留设备复现步骤，不能用另造的模型替代设备证据。
4. 做范围最小的修复，运行相关测试。通过后运行第 4 节总入口；任何产物相关代码/配置修改后重新生成和核对 APK。
5. 重新执行受影响的手机用例，并记录前后结果。C07 变化需同时复测 C02/C06/C13；设置/权限变化需复测 C01/C08/C09/C10；协议/符号变化需复测 C10/C11/C12。
6. 全部达到本阶段标准才写“该阶段通过”。有未测项就列明，不使用“全部完成”“长期稳定”等总括结论。

### 9.2 分流处理

| 首个失败点 | 先核实 | 处理边界与复验 |
| --- | --- | --- |
| Java/SDK/Wrapper 找不到、依赖下载失败 | 实际路径、运行 JDK、锁定版本、缓存和网络/TLS | 修正本机路径或按官方来源补依赖；不清空缓存、关闭 TLS 或升级全部依赖；重跑环境检查与总入口 |
| Java 编译、资源编译、lint 失败 | 首个具体报错文件、真实依赖 API、源与目标版本 | 修正调用/资源/具体规则；不全局压制 lint；重跑编译、测试、lint、构建和产物检查 |
| 测试失败或数量突然减少 | 测试清单、运行入口、实际失败断言及测试报告 | 修复生产行为或经证据确认的测试假设；不删断言凑 PASS；记录测试增删原因 |
| 安装失败 | APK 签名、设备原版本、包名和空间/系统要求 | 签名冲突找回原签名；不自动卸载或清数据；新包重新检查身份 |

| API 报请求格式/模型不支持 | 当日官方文档、实际账号模型、JSON 格式与参数 | 记录资料链接/日期，做小量合成日文请求；不能以猜测模型名批量试错；同步协议测试和实际结果 |
| 符号校验拒绝结果 | 输入已有符号、保护前后文本、模型返回的占位符 | 用合成数据复现，保留严格 ID/符号校验；不要删除检查只为展示译文；不日志输出订阅正文 |
| 卡片误关、旧内容重现 | 目标窗口与浮窗 ID、事件类型、页面代次、任务结束顺序 | 脱敏记录，不忽略全部同包/滚动/内容事件；修复后执行生命周期组合用例 |

| 文档说已完成而实际代码/结果不符 | 文档日期、对应提交/脏状态、运行包身份 | 先填写下方矛盾记录；按实测修正状态，不用旧 PASS 覆盖本次失败 |
