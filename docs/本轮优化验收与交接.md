# 本轮优化验收与交接（2026-09-16）

本轮代码版本标记：0.3.1-probe-review / 4。当前交付的是源码；七组桌面逻辑测试已通过，尚无本轮 APK、Android lint 或真机通过记录。此前实机截图继续作为旧版本的有效样本。

## 1. 同步到 Windows

把当前完整工程作为对照副本传到 Windows。让 Luna 先比较原工程和新副本，保留原机未提交的改动、local.properties、SDK 设置、debug.keystore 和已有构建缓存。不要用整个目录直接覆盖原机工程，更不要删除原机目录。

本轮没有推送 GitHub。在另一台电脑执行 git pull 不会自动取得尚未上传的这些修改。先在原机合并并审查差异，再按用户授权提交/同步。

同时保留 app、tools、scripts、docs、Gradle 配置和顶层文件；不要只复制新增 Java 文件。DomainSelfTest 已从 app/src/main 移至 tools，合并时也应移除原机旧路径下的测试副本，避免把测试代码装入 APK。

## 3. 先桌面验证，再安装

在项目根目录打开 PowerShell，确认 JAVA_HOME 指向已有可用 JDK（保留原 Android Studio JBR；源码编译目标仍是 Java 17），SDK 36 与本地依赖按原配置检查。

```powershell
& "$env:JAVA_HOME\bin\java.exe" -version
& .\scripts\verify-probe-logic.ps1
if ($LASTEXITCODE -ne 0) { throw 'Logic tests failed' }
.\gradlew.bat :app:compileDebugJavaWithJavac :app:lintDebug :app:assembleDebug
if ($LASTEXITCODE -ne 0) { throw 'Android verification failed' }
Get-FileHash -Algorithm SHA256 .\app\build\outputs\apk\debug\app-debug.apk
```

脚本使用同一份 tools/logic-sources.txt 和 tools/logic-test-classes.txt，预期出现七组 PASS。它不编译 Android 依赖类，因此不能跳过后面的 Gradle 命令。如果执行策略阻止脚本，按原电脑允许的方式运行，不修改全局执行策略。

### 两项构建配置变动

- 已移除项目 gradle.properties 中 D 盘 AAPT2 绝对路径。通常由 AGP 下载/使用匹配版本；如原机确有已复现的离线限制，可在原机用户级 Gradle 配置中使用经核实的覆盖路径，不重新写回跨电脑项目配置。
- 原机存在项目 debug.keystore 时继续使用它；缺失时使用 AGP 默认调试签名。不同电脑的新签名可能无法覆盖手机旧包，应先找回原机已有调试签名，不要自动卸载旧应用或删除用户数据。

## 4. 真机测试表（本轮均待执行）

| 用例 | 操作 | 通过标准 |
| --- | --- | --- |
| 安装身份 | 构建后核对包名、versionCode 4、versionName，再安装 | 成功启动；记录本轮 APK 哈希；不沿用旧包哈希 |
| 基础页面 | 合成页和目标 App 各取字一次，再切到其他 App | 浮窗只在允许页显示；没有非目标页内容 |
| 反向选择 | 先勾下方，再勾上方文字 | 列表、汇总、待翻译片段顺序一致，从上到下 |
| 空选择 | 全部取消勾选，然后关闭并重新取字 | 数量归零；新页面不继承旧选择 |
| 非正文 | 找含作者、时间、语音时长、标题的页面 | 明确这些 OCR 仍需手动排除；不得把它们误记为已自动过滤 |
| 长文与重复 | 对照原文首尾、换行、不同位置相同句子 | 不错序、不误去重；截断有提示；记录符号/漏字差异 |
| 多行消息 | 一条消息含多行 OCR | 显示片段数而非伪称消息数；不将“多行被分开”当作已完成消息分组 |
| 卡片交互 | 滚动卡片、拖动、关闭 | 可阅读可关闭；卡片自身滚动不造成页面误失效 |
| 迟到结果 | OCR 中关闭、切页或锁屏，等任务完成 | 旧卡片不重新出现；重新触发可用 |
| 连续使用 | 连续取字和关闭约 20 次，夹杂快速点击 | 无崩溃/多任务叠加；记录耗时与内存趋势，不用单次样本证明稳定 |
| 截图受限 | 遇到自然发生的截图失败场景 | 展示节点结果和错误码；不尝试绕过保护 |

测试记录只需：版本/设备系统、用例、步骤、实际结果、是否通过。订阅正文或截图本地保留，不进入公开 GitHub；分享截图前确认范围。

局部 OCR 与坐标映射、真正的消息分组、pageToken 绑定、符号保留校验、按消息 ID 匹配结果、取消/超时机制、API Key 加密存储、两位偶像档案、中文相邻显示。不要把当前 request preview 直接连到网络后宣称日常稳定版完成。
