# 2026-09-23 自动消息识别与底部翻译卡

## 本轮目标

根据聊天页面中的“成员姓名 + 时间”识别每条消息，把姓名、时间、右侧菜单、头像和媒体排除在翻译正文之外。翻译结果固定显示在屏幕底部，原聊天页面保持不变。

## 已完成的源码调整

- 新增 `MessageHeaderDetector`：识别已配置成员姓名和日期/时间，按同一消息容器收集后续正文。
- 新增 `MessageHeaderDetectorSelfTest`：覆盖两条消息、时间排除、菜单排除、日期时间格式和高置信度判断。
- `MessageGrouper` 新增 `autoSelectedIds`，只有高置信度、节点文字、正文角色且无警告的片段才会自动选择。
- `CandidateSelection` 新增自动选择入口；手动取消或追加仍然有效。
- `TranslatorAccessibilityService` 只在当前成员已匹配时启用自动选择，未确认成员时保持人工确认门禁。
- `CandidatePanel` 改为先显示自动识别摘要，节点和辅助候选移到“手动调整识别内容”区域。
- `TranslationPanel` 主按钮改为“翻译”，点击一次后才发起网络请求；打开识别卡本身不会请求 API。
- `TranslationReadingOverlay` 固定在底部安全区域，使用浅色、低对比度、圆角阅读卡；长文仍在卡内滚动。
