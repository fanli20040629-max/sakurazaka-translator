## 通俗说明

1. **选择成员**：原来点击下拉框可能再开一个普通弹窗，浮窗服务没有普通页面的窗口身份，可能因此崩溃。现在直接在翻译卡里展示单选项，点好后确认，不再开额外选择窗口。
2. **识别成员**：原来只认识少数标准标题栏。现在增加一种普通布局构成的顶部标题栏识别，但必须有明确的返回按钮、可信位置及完整姓名。设置中的姓名或完整别名也必须对应日文原名。不能把正文中提到的人名当作发送者。
3. **无障碍**：开关开启只代表授权，不代表服务仍连接。首页现在区分未授权、已授权但未连接、已连接。连接仍在时可刷新浮窗；已断开时，普通 App 无法强制系统重新绑定，只能提示恢复并保留诊断线索。先消除崩溃，再判断是否还存在系统后台限制。

## 识别的安全边界

- 继续要求姓名/别名完整匹配，允许空格规范化；不做模糊猜测，不读取正文来推断成员。
- 新标题容器必须完整处于窗口顶部 22% 内，高度不超过窗口 12%；标题必须位于该容器内。
- 返回按钮必须是同窗口、同容器直接子节点，具有明确的返回描述（如 `戻る`、`Back`），且可见可点击。不将菜单或一般图片当作返回键。
- 滚动列表/消息项、跨窗口关系、重复节点 ID、冲突标题、截断快照继续回退；不因上次选择了 A 就默认下一页仍是 A。
- 未知姓名提示配置实际全名/完整别名；缺标题、同名冲突仍要求本次确认。若持续缺失，先取得脱敏的顶部节点结构，再扩展适配，不能直接取消门禁。
- 快捷发送授权、API Key 加密、符号保护、收费请求确认边界不变。

4. 如已有故障正在发生，**先保存当前故障证据，再覆盖安装或重开服务**。检查：

```powershell

adb shell pidof com.fanli.sakurazakatranslator
adb logcat -b crash -d -v threadtime
```

只回传本应用相关的版本、启用/绑定/崩溃状态、异常类型和调用栈；完整系统输出仅本机临时存放，检查并脱敏。不得提交正文、无障碍原始 XML、截图、设备序列号、其他应用日志和 Key。不要先清空 logcat，否则可能丢失关键证据。

5. 原签名 `adb install -r` 覆盖安装新主 APK，避免卸载造成 Key/风格数据丢失。记录实际 APK SHA-256、签名和设备 versionCode/versionName。
6. 可选自动冒烟（无 Key、不打开真实聊天）：

```powershell
adb install -r app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk
adb shell am instrument -w com.fanli.sakurazakatranslator.test/com.fanli.sakurazakatranslator.capture.OverlaySmokeInstrumentation
```

只有输出 `PASS: member choices and confirmation work without an Activity token; no sends.` 且 `INSTRUMENTATION_CODE: -1` 才记通过。它在无 Activity token 的 Context 中切换/确认 20 次并断言未发送。此为自定义 smoke runner，使用上述 `am instrument`，不以普通 JUnit 测试数推断成功。

Instrumentation 会启动/替换测试进程，**应在连续性验收前运行**；结束后重新建立无障碍正常连接基线。不能把测试启动或 `am force-stop` 造成的停用当作正常退出失败，也不能用它证明真正的服务浮窗已测。
