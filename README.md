# 櫻坂翻译助手

当前版本是 P0.5 取字探针，目标是先验证 Android 16 真机上目标应用的无障碍节点、指定窗口截图和日文 OCR 能力。

## 当前状态

- P0：工程、Wrapper 和命令行 `assembleDebug` 已验证。
- P0.5：修复版已加入目标包过滤、任务生命周期保护、节点边界去重、可关闭滚动预览、内存截图和 bundled 日文 OCR；真机尚未验收。
- DeepSeek、API Key、翻译卡片和目标应用适配尚未接入。

## 构建

在项目根目录使用：

```powershell
.\gradlew.bat :app:assembleDebug
```

APK 生成后，以终端输出的绝对路径为准。不要提交 `local.properties`、API Key、截图、聊天正文或构建产物。

## 真机探针步骤

1. 安装 Debug APK。
2. 打开应用并进入 Android 无障碍设置，开启“櫻坂翻译助手”。
3. 打开目标 App 的测试页面，点击右上角“取字探针”。
4. 先在应用内置合成页验证重复文本、长文和图片文字，再记录节点文本、OCR 文本、页面类型和错误码；不要把原始订阅正文写入项目文档。

截图成功只表示截图接口成功，需核对 OCR 文本后才能判定正文取字通过。

## 已知限制

- 目标 App 包名和实际版本尚未由设备证据确认。
- 当前探针只在本应用合成页或用户保存的目标包名处显示按钮。
- 尚未验证目标应用的无障碍正文可读性、截图保护和 Android 16 敏感数据限制。
