# 櫻坂翻译助手

当前版本是 P0.5 取字探针，目标是先验证 Android 16 真机上目标应用的无障碍节点、指定窗口截图和日文 OCR 能力。

## 当前状态

- 2026-09-13：已完成[正文整理版开发方案 2.0](docs/PROBE_TEXT_OPTIMIZATION_HANDOFF.md)，包含代码差距、官方资料核对、实施步骤和验收矩阵；生产优化尚未实施。
- P0：工程、Wrapper 和命令行 `assembleDebug` 已验证。
- P0.5：旧探针已有安装、稳定卡片、合成及部分目标截图/OCR 记录；生命周期、正文结构和完整四类页面验收仍有缺口。旧逻辑自测 PASS 不代表这些行为全部通过。
- DeepSeek、API Key、翻译卡片和目标应用适配尚未接入。

## 构建

在项目根目录使用：

```powershell
.\gradlew.bat :app:assembleDebug
```

APK 生成后，以终端输出的绝对路径为准。不要提交 `local.properties`、API Key、截图、聊天正文或构建产物。

## 真机探针步骤

1. 安装 Debug APK，打开应用并先勾选“启用本页合成测试”。
2. 进入 Android 无障碍设置，开启“櫻坂翻译助手”。
3. 返回内置合成页，点击“取字探针”，先验证重复文本、长文和图片文字。
4. 记录节点文本、OCR 文本、页面类型和错误码；合成页通过后，再根据设备前台证据确认并保存目标 App 包名。

截图成功只表示截图接口成功，需核对 OCR 文本后才能判定正文取字通过。

## 已知限制

- 目标包名已有前台证据：`jp.co.sonymusic.communication.sakurazaka`；目标实际版本及当前连接状态在下次手机测试时核对。
- 当前探针只在本应用合成页或用户保存的目标包名处显示按钮。
- 已观察的目标节点能保留部分样本的符号和换行；长文、重复、截断、系统性页面/锁屏回归尚未完成，不能推广为所有页面可用。
